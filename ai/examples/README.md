# Examples

Referência canônica de código nesta sprint: `packages/ui/src/button/` (componente + story + index).
Novos exemplos entram aqui quando um padrão precisar de demonstração que não caiba numa rule
(ex.: block com slots, template de tela). Antes de criar exemplo novo, verifique se uma rule
com trecho certo/errado resolve — exemplo longo é contexto caro.
