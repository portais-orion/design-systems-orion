---
title: TableSkeletonRows
description: "Linhas de carregamento para uma `Table`, com larguras variadas para lembrar texto real."
---

Renderiza apenas `<tr>`: precisa estar dentro de um `TableBody`. `columns` deve bater com as colunas da tabela para as células não desalinharem.

Disponível em `@portais-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { TableSkeletonRows } from "@portais-orion/blocks/table-skeleton-rows";
```

O import por subpath traz só `table-skeleton-rows`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `rows` | `number` | `6` |
| `columns`\* | `number` | — |
| `withActionsColumn` | `boolean` | `false` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `TableSkeletonRows` aceita as props do elemento/primitivo que envolve.
