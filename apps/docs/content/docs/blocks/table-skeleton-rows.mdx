---
title: TableSkeletonRows
description: "Linhas de carregamento para uma `Table`, com larguras variadas para lembrar texto real."
---

Renderiza apenas `<tr>`: precisa estar dentro de um `TableBody`. `columns` deve bater com as colunas da tabela para as células não desalinharem.

Disponível em `@portais-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `rows` | `number` | `6` |
| `columns`\* | `number` | — |
| `withActionsColumn` | `boolean` | `false` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `TableSkeletonRows` aceita as props do elemento/primitivo que envolve.
