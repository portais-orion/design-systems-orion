title: DetailPageLayout
description: "Layout de página de detalhe de um registro: resumo, abas e conteúdo, com `aside` opcional para metadados e ações secundárias."
---

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { DetailPageLayout } from "@portais-orion/blocks/detail-page-layout";
```

O import por subpath traz só `detail-page-layout`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
