---
title: DetailPageLayout
description: "Layout de página de detalhe de um registro: resumo, abas e conteúdo, com `aside` opcional para metadados e ações secundárias."
---

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```
