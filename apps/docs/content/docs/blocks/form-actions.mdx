---
title: FormActions
description: "Barra de ações no rodapé de um formulário."
---

É só composição de slots: não cria botões nem textos — passe os seus em `primary`, `secondary` e `extra`. Com `sticky`, a barra gruda no rodapé em formulários longos.

Disponível em `@portais-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `primary` | `any` | — |
| `secondary` | `any` | — |
| `extra` | `any` | — |
| `align` | `"left" \| "right" \| "between"` | `right` |
| `sticky` | `boolean` | `false` |
| `className` | `string` | — |

Além destas, `FormActions` aceita as props do elemento/primitivo que envolve.
