---
title: PageHeader
description: "Cabeçalho principal da página: renderiza o `<h1>`, com descrição, um `eyebrow` opcional acima do título e slot de ações à direita."
---

Não conhece rota nem breadcrumb — combine com `Breadcrumbs` quando precisar.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `title`\* | `string` | — |
| `description` | `string` | — |
| `eyebrow` | `string` | — |
| `actions` | `any` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `PageHeader` aceita as props do elemento/primitivo que envolve.
