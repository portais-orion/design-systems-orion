# PageHeader

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Layout**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { PageHeader } from "@portais-orion/blocks";

export default function Example() {
  return (
    <PageHeader {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<PageHeader {...{ 		title: "Registros", 		description: "Gerencie os registros e acompanhe seus status.", 	}} />
```

### ComAcoes
```tsx
<PageHeader {...{ 		title: "Registros", 		description: "Gerencie os registros e acompanhe seus status.", 		actions: ( 			<> 				<Button variant="outline"> 					<Download /> Exportar 				</Button> 				<Button> 					<Plus /> Novo registro 				</Button> 			</> 		), 	}} />
```

### ComEyebrow
```tsx
<PageHeader {...{ 		eyebrow: "Operações", 		title: "Painel de acompanhamento", 	}} />
```

### SomenteTitulo
```tsx
<PageHeader {...{ title: "Configurações" }} />
```
