title: PageHeader
description: "Cabeçalho principal da página: renderiza o `<h1>`, com descrição, um `eyebrow` opcional acima do título e slot de ações à direita."
---

Não conhece rota nem breadcrumb — combine com `Breadcrumbs` quando precisar.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { PageHeader } from "@portais-orion/blocks/page-header";
```

O import por subpath traz só `page-header`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
