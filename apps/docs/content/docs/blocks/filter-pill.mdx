---
title: FilterPill
description: "Chip que mostra um filtro já aplicado, no formato \"rótulo · valor\"."
---

O botão de remover só aparece quando `onRemove` é passado. Para escolher o filtro, use `FiltersCard`; este bloco apenas exibe o que está ativo.

Disponível em `@portais-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `label`\* | `string` | — |
| `value` | `string \| number` | — |
| `onRemove` | `() => void` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `FilterPill` aceita as props do elemento/primitivo que envolve.
