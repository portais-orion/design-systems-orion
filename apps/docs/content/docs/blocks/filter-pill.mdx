title: FilterPill
description: "Chip que mostra um filtro já aplicado, no formato \"rótulo · valor\"."
---

O botão de remover só aparece quando `onRemove` é passado. Para escolher o filtro, use `FiltersCard`; este bloco apenas exibe o que está ativo.

Disponível em `@design-systems-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { FilterPill } from "@design-systems-orion/blocks/filter-pill";
```

O import por subpath traz só `filter-pill`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
