---

Presentational — não calcula datas de negócio, só posiciona o que recebe.

Disponível em `@portais-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { GanttChart } from "@portais-orion/blocks/gantt-chart";
```

O import por subpath traz só `gantt-chart`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `rangeStart`\* | `Date` | — | — |
| `rangeEnd`\* | `Date` | — | — |
| `rows`\* | `GanttRow[]` | — | — |
| `todayDate` | `Date` | — | Data marcada com uma linha vertical tracejada. Padrão: hoje. |
| `emptyMessage` | `string` | `Nenhum item no período.` | — |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `GanttChart` aceita as props do elemento/primitivo que envolve.
