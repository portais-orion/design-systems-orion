title: PresenceAvatarStack
description: "Pilha de avatares sobrepostos com indicador \"online\" e tooltip (nome + sublabel, ex.: página atual)."
---

Não conhece sockets/presença real-time — só renderiza a lista recebida via props.

Disponível em `@design-systems-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { PresenceAvatarStack } from "@design-systems-orion/blocks/presence-avatar-stack";
```

O import por subpath traz só `presence-avatar-stack`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |

Além destas, `PresenceAvatarStack` aceita as props do elemento/primitivo que envolve.
