Não faz upload nem valida — só exibe o que o consumidor já tem em estado local.

Disponível em `@design-systems-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { FileListItem } from "@design-systems-orion/blocks/file-list-item";
```

O import por subpath traz só `file-list-item`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `name`\* | `string` | — | — |
| `size` | `string \| number` | — | Já formatado (ex.: "1.4 KB") ou tamanho em bytes (formata em KB automaticamente). |
| `icon` | `ComponentType<{ className?: string; }>` | — | — |
| `onRemove` | `() => void` | — | — |
| `removeLabel` | `string` | `Remover` | — |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `FileListItem` aceita as props do elemento/primitivo que envolve.
