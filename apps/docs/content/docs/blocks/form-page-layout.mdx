title: FormPageLayout
description: "Layout de página de criar ou editar registro."
---

Sem `aside`, contém o formulário numa coluna estreita para não esticar demais as linhas; com `aside`, abre espaço lateral. Não cria o elemento `<form>` nem conhece biblioteca de formulário — isso fica com o consumidor.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { FormPageLayout } from "@portais-orion/blocks/form-page-layout";
```

O import por subpath traz só `form-page-layout`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
