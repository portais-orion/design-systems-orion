`onChange` dispara a cada tecla; `onDebouncedChange` espera `debounceMs` após a última digitação — use este último para não disparar uma requisição por caractere.

Disponível em `@design-systems-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { SearchBar } from "@design-systems-orion/blocks/search-bar";
```

O import por subpath traz só `search-bar`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `value`\* | `string` | — |
| `onChange`\* | `(value: string) => void` | — |
| `placeholder` | `string` | `Buscar...` |
| `debounceMs` | `number` | `300` |
| `onDebouncedChange` | `(value: string) => void` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `SearchBar` aceita as props do elemento/primitivo que envolve.
