title: StatusDot
description: "Indicador de status por tom semântico."
---

Sem `label` é só um ponto decorativo (`aria-hidden`), então o significado precisa vir do contexto; com `label` vira uma pílula com o texto legível.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `tone` | `"default" \| "success" \| "warning" \| "danger" \| "info" \| "muted"` | `default` |
| `label` | `string` | — |
| `className` | `string` | — |

Além destas, `StatusDot` aceita as props do elemento/primitivo que envolve.
