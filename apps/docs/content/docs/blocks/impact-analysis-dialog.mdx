Dados via props.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { ImpactAnalysisDialog } from "@portais-orion/blocks/impact-analysis-dialog";
```

O import por subpath traz só `impact-analysis-dialog`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
