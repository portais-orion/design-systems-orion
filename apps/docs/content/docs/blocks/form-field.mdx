title: FormField
description: "Agrupa rótulo, controle e mensagem de ajuda ou erro de um campo."
---

Agnóstico de biblioteca de formulário: `error` chega por prop. Informando `htmlFor`, as mensagens ganham os ids `<htmlFor>-description` e `<htmlFor>-error` — cabe ao consumidor referenciá-los no `aria-describedby` do controle, já que este bloco não clona os filhos.

Disponível em `@portais-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `label` | `any` | — |
| `htmlFor` | `string` | — |
| `description` | `any` | — |
| `error` | `any` | — |
| `required` | `boolean` | — |
| `className` | `string` | — |

Além destas, `FormField` aceita as props do elemento/primitivo que envolve.
