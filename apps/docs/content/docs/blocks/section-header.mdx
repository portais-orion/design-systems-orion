---
title: SectionHeader
description: "Cabeçalho de uma seção dentro da página, com título, descrição e ações."
---

Renderiza um `<h2>`: para o título principal da página use `PageHeader`.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `title`\* | `any` | — |
| `description` | `any` | — |
| `actions` | `any` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `SectionHeader` aceita as props do elemento/primitivo que envolve.
