# SectionHeader

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Layout**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { SectionHeader } from "@portais-orion/blocks";

export default function Example() {
  return (
    <SectionHeader {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<SectionHeader {...{ title: "Histórico" }} />
```

### WithDescription
```tsx
<SectionHeader {...{ title: "Histórico", description: "Eventos recentes do registro." }} />
```

### WithActions
```tsx
<SectionHeader {...{ 		title: "Anexos", 		actions: ( 			<Button variant="outline" size="sm"> 				Adicionar 			</Button> 		), 	}} />
```
