title: SectionHeader
description: "Cabeçalho de uma seção dentro da página, com título, descrição e ações."
---

Renderiza um `<h2>`: para o título principal da página use `PageHeader`.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { SectionHeader } from "@portais-orion/blocks/section-header";
```

O import por subpath traz só `section-header`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
