title: CrudModalHeader
description: "Cabeçalho para modais de criar, editar ou detalhar registro: ícone tonalizado, título, subtítulo e um slot para badges de contexto."
---

Vai dentro do `Dialog` do consumidor — não abre nem fecha nada por conta própria.

Disponível em `@portais-orion/blocks`, na categoria **Utilitários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `title`\* | `string` | — | — |
