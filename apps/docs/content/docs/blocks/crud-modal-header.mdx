# CrudModalHeader

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Utilities**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

