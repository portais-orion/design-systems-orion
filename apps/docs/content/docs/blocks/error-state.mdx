Quando não houve erro e a lista apenas não tem registros, use `EmptyState`.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { ErrorState } from "@portais-orion/blocks/error-state";
```

O import por subpath traz só `error-state`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `title` | `string` | `Não foi possível carregar os dados` |
| `description` | `string` | `Ocorreu um erro de comunicação. Tente novamente em alguns instantes.` |
| `action` | `any` | — |
| `className` | `string` | — |

Além destas, `ErrorState` aceita as props do elemento/primitivo que envolve.
