---
title: ConfirmDialog
description: "Modal de confirmação para uma ação, com estado de carregamento embutido."
---

Só fecha quando `onConfirm` resolve: se a promessa rejeitar, o modal permanece aberto e cabe ao chamador exibir o erro. Use `variant="danger"` para ações destrutivas.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `open`\* | `boolean` | — |
| `onOpenChange`\* | `(open: boolean) => void` | — |
| `title`\* | `string` | — |
| `description` | `string` | — |
| `confirmLabel` | `string` | `Confirmar` |
| `cancelLabel` | `string` | `Cancelar` |
| `variant` | `"default" \| "danger"` | `default` |
| `isLoading` | `boolean` | `false` |
| `onConfirm`\* | `() => void \| Promise<void>` | — |

\* Prop obrigatória.

Além destas, `ConfirmDialog` aceita as props do elemento/primitivo que envolve.
