---
title: ConfirmDialog
description: "Modal de confirmação para uma ação, com estado de carregamento embutido."
---

Só fecha quando `onConfirm` resolve: se a promessa rejeitar, o modal permanece aberto e cabe ao chamador exibir o erro. Use `variant="danger"` para ações destrutivas.

Disponível em `@design-systems-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { ConfirmDialog } from "@design-systems-orion/blocks/confirm-dialog";
```

O import por subpath traz só `confirm-dialog`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `open`\* | `boolean` | — |
| `onOpenChange`\* | `(open: boolean) => void` | — |
| `title`\* | `string` | — |
| `description` | `string` | — |
| `confirmLabel` | `string` | `Confirmar` |
| `cancelLabel` | `string` | `Cancelar` |
| `variant` | `"default" \| "danger"` | `default` |
| `isLoading` | `boolean` | `false` |
| `onConfirm`\* | `() => void \| Promise<void>` | — |

\* Prop obrigatória.

Além destas, `ConfirmDialog` aceita as props do elemento/primitivo que envolve.
