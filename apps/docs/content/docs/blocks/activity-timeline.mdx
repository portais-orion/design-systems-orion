Dados via props — não busca nada.

Disponível em `@design-systems-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { ActivityTimeline } from "@design-systems-orion/blocks/activity-timeline";
```

O import por subpath traz só `activity-timeline`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items`\* | `TimelineItem[]` | — |
| `emptyMessage` | `string` | `Nenhum evento registrado.` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `ActivityTimeline` aceita as props do elemento/primitivo que envolve.
