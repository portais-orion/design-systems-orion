---
title: FormSection
description: "Agrupa campos relacionados sob um título, separando blocos de um formulário longo."
---

Renderiza um `<section>` com `<h3>`; use `FieldGroup` dentro para distribuir os campos em colunas.

Disponível em `@portais-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { FormSection } from "@portais-orion/blocks/form-section";
```

O import por subpath traz só `form-section`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
