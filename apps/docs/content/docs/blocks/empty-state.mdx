# EmptyState

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Feedback**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { EmptyState } from "@portais-orion/blocks";

export default function Example() {
  return (
    <EmptyState {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<EmptyState {...{ 		title: "Nenhum registro encontrado", 		description: "Tente ajustar os filtros ou criar um novo registro.", 	}} />
```

### ComAcao
```tsx
<EmptyState {...{ 		title: "Nenhum item cadastrado", 		description: "Cadastre o primeiro item para começar.", 		icon: Inbox, 		action: <Button size="sm">Novo registro</Button>, 	}} />
```

### BuscaSemResultado
```tsx
<EmptyState {...{ 		title: "Nenhum resultado para a busca", 		icon: SearchX, 		action: ( 			<Button variant="outline" size="sm"> 				Limpar busca 			</Button> 		), 	}} />
```

### Minimo
```tsx
<EmptyState {...{ title: "Nada por aqui" }} />
```
