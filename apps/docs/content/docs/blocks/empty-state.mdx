---
title: EmptyState
description: "Estado vazio de uma lista ou área de conteúdo."
---

Diz o que está faltando e, pelo slot `action`, oferece a saída (criar registro, limpar filtros). Para falha de carregamento use `ErrorState`.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

| Prop | Tipo | Padrão |

Além destas, `EmptyState` aceita as props do elemento/primitivo que envolve.
