# LauncherCard

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Data Display**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { LauncherCard } from "@portais-orion/blocks";

export default function Example() {
  return (
    <LauncherCard {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<LauncherCard {...{ 		icon: Boxes, 		title: "Gestão de Demandas", 		description: "Acompanhe e programe as demandas operacionais.", 		cta: "Abrir →", 	}} />
```

### Clicavel
```tsx
<LauncherCard {...{ 		icon: Truck, 		title: "Acompanhamento de Cargas", 		description: "Monitoramento de cargas em trânsito.", 		cta: "Abrir →", 		onClick: () => {}} />
```
