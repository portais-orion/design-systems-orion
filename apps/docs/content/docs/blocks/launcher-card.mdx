---
title: LauncherCard
description: "Card de entrada para um módulo, usado nas grades de home."
---

Não conhece rota: passe `onClick` (e navegue com o router do consumidor) ou envolva o card com o seu próprio link. Com `onClick`, renderiza um `<button>`.

Disponível em `@portais-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { LauncherCard } from "@portais-orion/blocks/launcher-card";
```

O import por subpath traz só `launcher-card`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
