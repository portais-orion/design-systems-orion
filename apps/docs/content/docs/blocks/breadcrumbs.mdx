# Breadcrumbs

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Navigation**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { Breadcrumbs } from "@portais-orion/blocks";

export default function Example() {
  return (
    <Breadcrumbs {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<Breadcrumbs {...{ 		items: [{ label: "Início", href: "#" }} />
```

### WithLinks

<Breadcrumbs {...{ 		items: [ 			{ label: "Início", href: "#" }} />

### LongTrail
