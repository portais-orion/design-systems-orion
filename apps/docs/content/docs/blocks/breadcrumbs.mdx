---
title: Breadcrumbs
description: "Trilha de navegação até a página atual."
---

Não conhece o router: passe `renderLink` para usar o `Link` do seu framework — sem ele, cai em uma âncora comum e o consumidor perde a navegação client-side. O último item é marcado com `aria-current="page"`.

Disponível em `@portais-orion/blocks`, na categoria **Navegação**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items`\* | `BreadcrumbItem[]` | — |
| `renderLink` | `RenderLink` | — |
| `separator` | `any` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `Breadcrumbs` aceita as props do elemento/primitivo que envolve.
