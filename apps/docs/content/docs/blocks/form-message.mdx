# FormMessage

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Forms**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">

  </div>
</Preview>

```tsx
import { FormMessage } from "@portais-orion/blocks";

export default function Example() {
  return (
    <FormMessage {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<FormMessage {...{ children: "Texto de apoio do campo." }} />
```

### ErrorStory


### Warning
