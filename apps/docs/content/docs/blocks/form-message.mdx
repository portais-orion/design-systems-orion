---
title: FormMessage
description: "Mensagem de apoio ou validação sob um campo."
---

Com `tone="error"` vira `role="alert"` e é anunciada de imediato; ligue o `id` ao `aria-describedby` do campo para associar mensagem e controle.

Disponível em `@design-systems-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { FormMessage } from "@design-systems-orion/blocks/form-message";
```

O import por subpath traz só `form-message`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `tone` | `"default" \| "error" \| "warning" \| "success"` | `default` |
| `className` | `string` | — |
| `id` | `string` | — |

Além destas, `FormMessage` aceita as props do elemento/primitivo que envolve.
