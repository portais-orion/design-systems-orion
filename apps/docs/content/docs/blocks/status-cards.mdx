# StatusCards

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Data Display**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>

  </div>
</Preview>

```tsx
import { StatusCards } from "@portais-orion/blocks";

export default function Example() {
  return (
    <StatusCards {/* props */} />
  )
}
```
