Um item com `onClick` vira botão e pode servir de filtro rápido — use `active` para marcar o que está aplicado; sem `onClick`, é apenas leitura.

Disponível em `@design-systems-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { StatusCards } from "@design-systems-orion/blocks/status-cards";
```

O import por subpath traz só `status-cards`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items`\* | `StatusCardItem[]` | — |
| `columns` | `2 \| 3 \| 4` | `4` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `StatusCards` aceita as props do elemento/primitivo que envolve.
