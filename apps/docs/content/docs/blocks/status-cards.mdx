description: "Faixa de indicadores no topo de uma listagem ou dashboard."
---

Um item com `onClick` vira botão e pode servir de filtro rápido — use `active` para marcar o que está aplicado; sem `onClick`, é apenas leitura.

Disponível em `@portais-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items`\* | `StatusCardItem[]` | — |
| `columns` | `2 \| 3 \| 4` | `4` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `StatusCards` aceita as props do elemento/primitivo que envolve.
