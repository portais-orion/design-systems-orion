---
title: ContentCard
description: "Painel de conteúdo com cabeçalho opcional (título, descrição e ações)."
---

Monta a estrutura de `Card` mais comum sem que você repita header e content a cada uso; o cabeçalho só é renderizado se houver algum deles.

Disponível em `@portais-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```
