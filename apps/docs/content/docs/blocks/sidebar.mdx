---
title: Sidebar
description: "Navegação lateral do portal, dirigida por dados: a árvore vem em `navigation` e as peças internas (item, grupo, submenu) não são exportadas, para que os portais não montem variações divergentes."
---

Colapsada, os rótulos viram tooltips. Não conhece rota nem permissão — injete `renderLink` e `canAccessItem`. Normalmente usada via `AppShell`.

Disponível em `@portais-orion/blocks`, na categoria **Navegação**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `brand` | `any` | — |
| `navigation`\* | `NavigationItem[]` | — |
| `activeItemId` | `string` | — |
| `collapsed` | `boolean` | — |
| `defaultCollapsed` | `boolean` | `false` |
| `onCollapsedChange` | `(collapsed: boolean) => void` | — |
| `canAccessItem` | `CanAccessNavigationItem` | — |
| `renderLink` | `RenderLink` | `({ href, children, className, ...props }) => ( 	<a href={href} className={className} {...props}> 		{children} 	</a> )` |
| `onNavigate` | `() => void` | — |
| `footer` | `any` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `Sidebar` aceita as props do elemento/primitivo que envolve.
