# Sidebar

Um componente da biblioteca `@portais-orion/blocks` agrupado em **Navigation**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { Sidebar } from "@portais-orion/blocks";

export default function Example() {
  return (
    <Sidebar {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<Sidebar {...{ brand: <Marca />, navigation: NAV, activeItemId: "registros" }} />
```

### Collapsed
```tsx
<Sidebar {...{ brand: <Marca />, navigation: NAV, activeItemId: "registros", defaultCollapsed: true }} />
```

### WithGroups
```tsx
<Sidebar {...{ 		brand: <Marca />, 		activeItemId: "registros", 		navigation: [ 			{ 				id: "g-operacao", 				label: "Operação", 				meta: { group: true }} />
```

### WithSubmenus
```tsx
<Sidebar {...{ brand: <Marca />, navigation: NAV }} />
```

### WithBadges
```tsx
<Sidebar {...{ 		brand: <Marca />, 		navigation: [ 			{ id: "inicio", label: "Início", href: "#", icon: Home }} />
```

### WithDisabledItems
```tsx
<Sidebar {...{ 		brand: <Marca />, 		navigation: [ 			...NAV.slice(0, 2), 			{ id: "restrito", label: "Em breve", icon: Lock, disabled: true, href: "#" }} />
```

### WithFilteredItems
```tsx
<Sidebar {...{ 		brand: <Marca />, 		navigation: NAV, 		canAccessItem: (item) => item.id !== "usuarios", 	}} />
```

### WithFooter
```tsx
<Sidebar {...{ 		brand: <Marca />, 		navigation: NAV, 		activeItemId: "registros", 		footer: ( 			<div className="flex w-full items-center gap-2.5"> 				<Avatar className="size-8"> 					<AvatarFallback>MA</AvatarFallback> 				</Avatar> 				<div className="min-w-0 flex-1 leading-tight"> 					<p className="truncate text-xs font-semibold">Usuário Exemplo</p> 					<p className="truncate text-[0.65rem] text-sidebar-foreground/60">Administrador</p> 				</div> 				<button 					type="button" 					aria-label="Sair" 					className="flex size-7 shrink-0 items-center justify-center rounded text-sidebar-foreground/60 outline-none transition-colors hover:text-sidebar-foreground focus-visible:ring-2 focus-visible:ring-sidebar-ring" 				> 					<LogOut className="size-4" /> 				</button> 			</div> 		), 	}} />
```
