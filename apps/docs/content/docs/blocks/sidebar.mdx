---
title: Sidebar
description: "Navegação lateral do portal, dirigida por dados: a árvore vem em `navigation` e as peças internas (item, grupo, submenu) não são exportadas, para que os portais não montem variações divergentes."
---

Colapsada, os rótulos viram tooltips. Não conhece rota nem permissão — injete `renderLink` e `canAccessItem`. Normalmente usada via `AppShell`.

Disponível em `@design-systems-orion/blocks`, na categoria **Navegação**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { Sidebar } from "@design-systems-orion/blocks/sidebar";
```

O import por subpath traz só `sidebar`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `brand` | `any` | — | — |
| `activeModule` | `SidebarModule` | — | — |
| `navigation`\* | `NavigationItem[]` | — | — |
| `activeItemId` | `string` | — | — |
| `collapsed` | `boolean` | — | — |
| `defaultCollapsed` | `boolean` | `false` | — |
| `onCollapsedChange` | `(collapsed: boolean) => void` | — | — |
| `collapsible` | `boolean` | `true` | Botão de colapso na borda. Padrão `true`. Desligue onde a sidebar não é lateral fixa (ex.: dentro do drawer mobile do AppShell), ou quando o portal já oferece o gesto em outro lugar. Mesmo desligado, `collapsed` continua valendo — só o botão some. |
| `canAccessItem` | `CanAccessNavigationItem` | — | — |
| `renderLink` | `RenderLink` | `({ href, children, className, ...props }) => ( 	<a href={href} className={className} {...props}> 		{children} 	</a> )` | — |
| `onNavigate` | `() => void` | — | — |
| `footer` | `any` | — | — |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `Sidebar` aceita as props do elemento/primitivo que envolve.
