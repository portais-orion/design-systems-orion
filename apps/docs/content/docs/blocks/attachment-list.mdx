Não sabe renderizar o preview do arquivo em si — isso fica com o consumidor.

Disponível em `@design-systems-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { AttachmentList } from "@design-systems-orion/blocks/attachment-list";
```

O import por subpath traz só `attachment-list`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items`\* | `AttachmentItem[]` | — |
| `onSelect` | `(item: AttachmentItem) => void` | — |
| `onRemove` | `(item: AttachmentItem) => void` | — |
| `removeLabel` | `string` | `Remover` |
| `emptyMessage` | `string` | `Nenhum anexo.` |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `AttachmentList` aceita as props do elemento/primitivo que envolve.
