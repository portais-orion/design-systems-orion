Escolha o tamanho por `size` em vez de sobrescrever largura via `className`.

Disponível em `@design-systems-orion/blocks`, na categoria **Utilitários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { CrudModalFrame } from "@design-systems-orion/blocks/crud-modal-frame";
```

O import por subpath traz só `crud-modal-frame`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
