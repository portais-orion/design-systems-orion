---
title: FiltersCard
description: "Card colapsável que abriga os controles de filtro de uma listagem."
---

Não conhece os filtros: renderiza o que vier em `children` e avisa por `onClear`. Funciona não-controlado (`defaultOpen`) ou controlado (`open` + `onOpenChange`).

Disponível em `@design-systems-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { FiltersCard } from "@design-systems-orion/blocks/filters-card";
```

O import por subpath traz só `filters-card`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `title` | `string` | — | — |
| `icon` | `ComponentType<{ className?: string; }>` | — | — |

| `onOpenChange` | `(open: boolean) => void` | — | — |

| `clearLabel` | `string` | — | — |
| `children`\* | `any` | — | Controles de filtro (SearchBar, selects, etc.). |
| `footer` | `any` | — | Ações extras no footer, à esquerda do "Limpar". |

\* Prop obrigatória.

Além destas, `FiltersCard` aceita as props do elemento/primitivo que envolve.
