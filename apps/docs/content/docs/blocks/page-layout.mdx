---
title: PageLayout
description: "Esqueleto base de uma página: padding, largura máxima e o espaçamento vertical padrão entre header, conteúdo e footer."
---

Não inclui sidebar nem breadcrumb — isso é o `AppShell`. Os layouts especializados (`ListPageLayout`, `FormPageLayout`, …) são construídos sobre este.

Disponível em `@design-systems-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { PageLayout } from "@design-systems-orion/blocks/page-layout";
```

O import por subpath traz só `page-layout`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `header` | `any` | — |
| `footer` | `any` | — |
| `className` | `string` | — |
| `contentClassName` | `string` | — |
| `maxWidth` | `"none" \| "screen-xl" \| "screen-2xl"` | `none` |

Além destas, `PageLayout` aceita as props do elemento/primitivo que envolve.
