---
title: PageLayout
description: "Esqueleto base de uma página: padding, largura máxima e o espaçamento vertical padrão entre header, conteúdo e footer."
---

Não inclui sidebar nem breadcrumb — isso é o `AppShell`. Os layouts especializados (`ListPageLayout`, `FormPageLayout`, …) são construídos sobre este.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `header` | `any` | — |
| `footer` | `any` | — |
| `className` | `string` | — |
| `contentClassName` | `string` | — |
| `maxWidth` | `"none" \| "screen-xl" \| "screen-2xl"` | `none` |

Além destas, `PageLayout` aceita as props do elemento/primitivo que envolve.
