title: TableToggle
description: "Switch compacto (36×20) para alternar um valor booleano diretamente numa célula de tabela, sem label ao lado."
---

Para alternância em formulário, use o `Switch` padrão do `@portais-orion/ui`.

Disponível em `@portais-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { TableToggle } from "@portais-orion/blocks/table-toggle";
```

O import por subpath traz só `table-toggle`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `checked`\* | `boolean` | — |
| `onToggle`\* | `() => void` | — |
| `disabled` | `boolean` | `false` |
| `aria-label` | `string` | — |
| `className` | `string` | — |

\* Prop obrigatória.

Além destas, `TableToggle` aceita as props do elemento/primitivo que envolve.
