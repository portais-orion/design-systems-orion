---
title: ListPageLayout
description: "Layout de página de listagem: cabeçalho, indicadores, barra de ferramentas, filtros aplicados e o conteúdo (normalmente um `DataTable`)."
---

Tudo por slots — o layout não conhece dados nem filtros, só os posiciona.

Disponível em `@portais-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```
