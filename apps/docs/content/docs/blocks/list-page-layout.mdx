---
title: ListPageLayout
description: "Layout de página de listagem: cabeçalho, indicadores, barra de ferramentas, filtros aplicados e o conteúdo (normalmente um `DataTable`)."
---

Tudo por slots — o layout não conhece dados nem filtros, só os posiciona. Use `surface="card"` para o visual de superfície única (filtros + conteúdo + footer dentro do mesmo card com borda/sombra).

Disponível em `@design-systems-orion/blocks`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { ListPageLayout } from "@design-systems-orion/blocks/list-page-layout";
```

O import por subpath traz só `list-page-layout`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `header` | `any` | — | — |
| `stats` | `any` | — | — |
| `toolbar` | `any` | — | — |
| `filters` | `any` | — | — |
| `content`\* | `any` | — | — |
| `footer` | `any` | — | — |
| `surface` | `"transparent" \| "card"` | `transparent` | `"card"` envolve filters+content+footer numa superfície com borda, sombra e cantos arredondados (padrão Aurora-like). Default `"transparent"`: cada slot fica solto, como hoje. |
| `loading` | `boolean` | `false` | Cobre `content` com `LoadingOverlay` enquanto `true`. Não afeta `stats`/`toolbar`/`filters`. |
| `loadingLabel` | `string` | — | — |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `ListPageLayout` aceita as props do elemento/primitivo que envolve.
