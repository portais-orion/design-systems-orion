---

Use `ICON_OPTIONS` para montar um seletor de ícones no formulário de cadastro do módulo.

Disponível em `@portais-orion/blocks`, na categoria **Utilitários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { ModuleIcon, ICON_OPTIONS, ICON_MAP } from "@portais-orion/blocks/module-icon";
```

O import por subpath traz só `module-icon`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `icon` | `string` | — | Chave do catálogo (`ICON_MAP`); cai em `package` se ausente ou desconhecida. |
| `size` | `"sm" \| "md"` | `md` | — |
| `className` | `string` | — | — |

Além destas, `ModuleIcon` aceita as props do elemento/primitivo que envolve.
