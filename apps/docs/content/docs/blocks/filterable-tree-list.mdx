---
title: FilterableTreeList
description: "Lista hierárquica com expand/collapse por nó e auto-expansão forçada (`forceOpenIds`, tipicamente calculado pelo consumidor a partir de um termo de busca)."
---

Não sabe filtrar nem buscar — recebe a árvore e o estado prontos.

Disponível em `@design-systems-orion/blocks`, na categoria **Navegação**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { FilterableTreeList } from "@design-systems-orion/blocks/filterable-tree-list";
```

O import por subpath traz só `filterable-tree-list`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `nodes`\* | `TreeNode[]` | — | — |
| `openIds`\* | `Set<string>` | — | Nós abertos por interação direta do usuário. |
| `onToggle`\* | `(id: string) => void` | — | — |
| `forceOpenIds` | `Set<string>` | — | Nós forçados a abrir porque a busca combinou em algum descendente. |
| `onSelectNode` | `(node: TreeNode) => void` | — | — |
| `emptyMessage` | `string` | `Nenhum resultado encontrado.` | — |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `FilterableTreeList` aceita as props do elemento/primitivo que envolve.
