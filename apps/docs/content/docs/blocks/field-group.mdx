`columns` é o teto em telas largas, não um número fixo.

Disponível em `@portais-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { FieldGroup } from "@portais-orion/blocks/field-group";
```

O import por subpath traz só `field-group`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

| Prop | Tipo | Padrão |

| `columns` | `1 \| 2 \| 3 \| 4` | `2` |

Além destas, `FieldGroup` aceita as props do elemento/primitivo que envolve.
