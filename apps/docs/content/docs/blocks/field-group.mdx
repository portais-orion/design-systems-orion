`columns` é o teto em telas largas, não um número fixo.

Disponível em `@portais-orion/blocks`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

<ComponentPreview name="blocks/field-group" story="OneColumn" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `columns` | `1 \| 2 \| 3 \| 4` | `2` |
| `className` | `string` | — |

Além destas, `FieldGroup` aceita as props do elemento/primitivo que envolve.
