---
title: LoadingOverlay
description: "Cobre uma área com um indicador de carregamento sem desmontar o conteúdo, o que evita o salto de layout ao alternar."
---

Bloqueia a interação e marca `aria-busy` apenas enquanto `loading` é verdadeiro.

Disponível em `@portais-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/blocks
```

<ComponentPreview name="blocks/loading-overlay" story="Default" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `loading`\* | `boolean` | — |
| `label` | `string` | — |
| `className` | `string` | — |
| `overlayClassName` | `string` | — |

\* Prop obrigatória.

Além destas, `LoadingOverlay` aceita as props do elemento/primitivo que envolve.
