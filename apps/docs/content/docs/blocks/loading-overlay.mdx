title: LoadingOverlay
description: "Cobre uma área com um indicador de carregamento sem desmontar o conteúdo, o que evita o salto de layout ao alternar."
---

Bloqueia a interação e marca `aria-busy` apenas enquanto `loading` é verdadeiro.

Disponível em `@design-systems-orion/blocks`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { LoadingOverlay } from "@design-systems-orion/blocks/loading-overlay";
```

O import por subpath traz só `loading-overlay`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `loading`\* | `boolean` | — |
| `label` | `string` | — |
| `className` | `string` | — |
| `overlayClassName` | `string` | — |

\* Prop obrigatória.

Além destas, `LoadingOverlay` aceita as props do elemento/primitivo que envolve.
