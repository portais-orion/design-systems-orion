title: ComparisonDiffView
description: "Comparação lado a lado entre duas ou mais entidades, organizada em grupos (ex.: \"Permissões\", \"Módulos\"), cada um com colunas coloridas por tom."
---

Dados via props — não busca nem calcula o diff.

Disponível em `@design-systems-orion/blocks`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @design-systems-orion/ui junto.
pnpm add @design-systems-orion/blocks
```

## Import

```tsx
import { ComparisonDiffView } from "@design-systems-orion/blocks/comparison-diff-view";
```

O import por subpath traz só `comparison-diff-view`. Importar de `@design-systems-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
