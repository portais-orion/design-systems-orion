---
title: Pagination
description: "Navegação entre páginas de uma listagem, com contagem de resultados e seletor de itens por página."
---

Casa com o envelope `{ data, total, page, limit }` da API. Por padrão não renderiza nada quando `total` é zero; use `showWhenEmpty` para manter o rodapé visível e desabilitado nesse caso. Trocar o limite volta para a primeira página.

Disponível em `@portais-orion/blocks`, na categoria **Tabelas**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
# Os blocks compõem as primitives, então este já traz @portais-orion/ui junto.
pnpm add @portais-orion/blocks
```

## Import

```tsx
import { Pagination } from "@portais-orion/blocks/pagination";
```

O import por subpath traz só `pagination`. Importar de `@portais-orion/blocks` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `page`\* | `number` | — | — |
| `limit`\* | `number` | — | — |
| `total`\* | `number` | — | — |
| `limitOptions` | `number[]` | `[10, 20, 50, 100]` | — |
| `onPageChange`\* | `(page: number) => void` | — | — |
| `onLimitChange` | `(limit: number) => void` | — | — |
| `showWhenEmpty` | `boolean` | `false` | Mantém o rodapé visível (com navegação desabilitada e contadores zerados) quando `total` é zero, em vez de não renderizar nada. Default `false` preserva o comportamento anterior. |
| `itemLabel` | `string` | `resultados` | Nome do item na contagem (ex.: "clientes", "portos"). Default "resultados". |
| `className` | `string` | — | — |

\* Prop obrigatória.

Além destas, `Pagination` aceita as props do elemento/primitivo que envolve.
