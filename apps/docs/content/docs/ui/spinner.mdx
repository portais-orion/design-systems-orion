Com `label`, vira uma live region (`role="status"`) que anuncia o texto; sem `label`, fica `aria-hidden` e quem anuncia o estado é o contexto ao redor.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | — | — |
| `label` | `string` | — | Texto anunciado a leitores de tela. Sem ele o spinner é decorativo. |

Além destas, `Spinner` aceita as props do elemento/primitivo que envolve.
