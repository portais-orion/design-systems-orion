---
title: Select
description: "Seleção de uma opção entre poucas, a partir de uma lista fechada."
---

Quando a lista é longa e pede busca, use `Combobox`; para várias opções ao mesmo tempo, `MultiSelect`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import {
	Select,
	SelectValue,
	SelectTrigger,
	SelectContent,
	SelectItem,
} from "@portais-orion/ui/select";
```

O import por subpath traz só `select`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

### SelectValue

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `items` | `{ value: string; label: string; }[]` | — |

### SelectContent

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `position` | `"popper" \| "item-aligned"` | `popper` |

Além destas, `Select` aceita as props do elemento/primitivo que envolve.
