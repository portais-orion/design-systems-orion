---
title: Popover
description: "Painel flutuante ancorado a um gatilho, para conteúdo secundário e interativo."
---

Para texto curto e apenas informativo use `Tooltip`; para uma lista de ações, `DropdownMenu`.

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/popover" story="Default" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `sideOffset` | `number` | `6` |
| `align` | `"center" \| "start" \| "end"` | `center` |

Além destas, `Popover` aceita as props do elemento/primitivo que envolve.
