Para texto curto e apenas informativo use `Tooltip`; para uma lista de ações, `DropdownMenu`.

Disponível em `@design-systems-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import {
	Popover,
	PopoverTrigger,
	PopoverContent,
	PopoverClose,
} from "@design-systems-orion/ui/popover";
```

O import por subpath traz só `popover`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `sideOffset` | `number` | `6` |
| `align` | `"center" \| "start" \| "end"` | `center` |

Além destas, `Popover` aceita as props do elemento/primitivo que envolve.
