# Textarea

Um componente da biblioteca `@portais-orion/ui` agrupado em **Forms**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">
    Substitua este texto pela declaração real do componente com suas props obrigatórias.
  </div>
</Preview>

```tsx
import { Textarea } from "@portais-orion/ui";

export default function Example() {
  return (
    <Textarea {/* props */} />
  )
}
```

## Exemplos

### Default
```tsx
<Textarea {...{ 		placeholder: "Type your message here.", 	}} />
```

### WithLabel
Consulte o Storybook para a variação `WithLabel`.

### Disabled
```tsx
<Textarea {...{ 		disabled: true, 		placeholder: "Type your message here.", 	}} />
```
