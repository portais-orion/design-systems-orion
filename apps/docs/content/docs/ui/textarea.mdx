title: Textarea
description: "Campo de texto de múltiplas linhas."
---

Não cresce sozinho com o conteúdo: ajuste a altura por `className` ou `rows`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/textarea" story="Default" />

## API Reference

`Textarea` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
