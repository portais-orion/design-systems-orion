title: Label
description: "Rótulo de um campo de formulário."
---

Passe `htmlFor` com o `id` do controle — sem isso o clique no texto não foca o campo e o leitor de tela não associa rótulo e campo.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

<ComponentPreview name="ui/label" story="Default" />

## API Reference

`Label` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
