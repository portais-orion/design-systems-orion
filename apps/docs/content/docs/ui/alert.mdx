title: Alert
description: "Mensagem de destaque exibida no fluxo da página, anunciada por leitores de tela via `role=\"alert\"`."
---

Componha com `AlertTitle` e `AlertDescription`; um `<svg>` como primeiro filho é posicionado automaticamente à esquerda.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"default" \| "destructive" \| "info"` | — |

Além destas, `Alert` aceita as props do elemento/primitivo que envolve.
