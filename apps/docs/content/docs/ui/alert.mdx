Componha com `AlertTitle` e `AlertDescription`; um `<svg>` como primeiro filho é posicionado automaticamente à esquerda.

Disponível em `@design-systems-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Alert, AlertTitle, AlertDescription } from "@design-systems-orion/ui/alert";
```

O import por subpath traz só `alert`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
