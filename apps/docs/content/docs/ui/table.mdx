Primitiva de marcação: já embrulha a `<table>` num contêiner com rolagem horizontal, mas não traz ordenação, paginação nem estados de vazio/erro — para isso use `DataTable` (blocks).

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/table" story="Default" />

## API Reference

`Table` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.

## Storybook

Todas as variações de `Table`, com controles interativos, vivem no
[Storybook](http://localhost:6006) do monorepo.
