`value` ausente ou `null` significa progresso indeterminado e renderiza uma barra animada.

Disponível em `@design-systems-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Progress } from "@design-systems-orion/ui/progress";
```

O import por subpath traz só `progress`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `max` | `number` | `100` | The maximum value. Valor que representa 100%. |
| `value` | `number` | `null` | Progresso atual. `null` (padrão) rende a barra indeterminada. |
| `indicatorClassName` | `string` | — | Classes aplicadas à barra preenchida, não ao trilho. |

Além destas, `Progress` aceita as props do elemento/primitivo que envolve.
