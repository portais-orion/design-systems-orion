---
title: Checkbox
description: "Caixa de seleção para escolhas independentes (marcar/desmarcar)."
---

Controle com `checked` e `onCheckedChange`; associe um `Label` via `id`/`htmlFor`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import { Checkbox } from "@portais-orion/ui/checkbox";
```

O import por subpath traz só `checkbox`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
