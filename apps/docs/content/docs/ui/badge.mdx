---
title: Badge
description: "Etiqueta compacta para status, categoria ou contagem."
---

É um elemento estático: para algo clicável use `Button`.

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

<ComponentPreview name="ui/badge" story="Default" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "tinted" \| "success" \| "warning"` | — |

Além destas, `Badge` aceita as props do elemento/primitivo que envolve.
