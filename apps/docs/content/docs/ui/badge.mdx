title: Badge
description: "Etiqueta compacta para status, categoria ou contagem."
---

É um elemento estático: para algo clicável use `Button`.

Disponível em `@design-systems-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Badge } from "@design-systems-orion/ui/badge";
```

O import por subpath traz só `badge`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
