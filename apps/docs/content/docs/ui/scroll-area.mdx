---
title: ScrollArea
description: "Região rolável com barra de rolagem estilizada por tokens, consistente entre navegadores."
---

Exige altura ou largura limitada no próprio elemento ou no pai — sem limite não há o que rolar.

Disponível em `@portais-orion/ui`, na categoria **Layout**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/scroll-area" story="Vertical" />

## API Reference

`ScrollArea` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
