title: ScrollArea
description: "Região rolável com barra de rolagem estilizada por tokens, consistente entre navegadores."
---

Exige altura ou largura limitada no próprio elemento ou no pai — sem limite não há o que rolar.

Disponível em `@design-systems-orion/ui`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { ScrollArea, ScrollBar } from "@design-systems-orion/ui/scroll-area";
```

O import por subpath traz só `scroll-area`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
