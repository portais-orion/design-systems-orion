---
title: Tooltip
description: "Rótulo curto que aparece ao focar ou passar o mouse sobre o gatilho."
---

Só aparece no hover/foco, então não coloque aqui informação essencial nem conteúdo interativo — para isso use `Popover`. Requer um `TooltipProvider` acima na árvore.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `top` |
| `sideOffset` | `number` | `4` |

Além destas, `Tooltip` aceita as props do elemento/primitivo que envolve.
