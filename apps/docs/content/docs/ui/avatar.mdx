Use como raiz de `AvatarImage` e `AvatarFallback` — o fallback aparece enquanto a imagem carrega ou quando ela falha.

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@portais-orion/ui/avatar";
```

O import por subpath traz só `avatar`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
