title: Avatar
description: "Imagem circular de identificação de uma pessoa ou entidade."
---

Use como raiz de `AvatarImage` e `AvatarFallback` — o fallback aparece enquanto a imagem carrega ou quando ela falha.

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

`Avatar` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
