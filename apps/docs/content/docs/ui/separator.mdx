Na vertical, exige que o pai tenha altura definida — o traço ocupa 100% da altura disponível.

Disponível em `@portais-orion/ui`, na categoria **Layout**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import { Separator } from "@portais-orion/ui/separator";
```

O import por subpath traz só `separator`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
