---
title: RadioGroup
description: "Escolha de exatamente uma opção entre poucas, todas visíveis ao mesmo tempo."
---

Controle com `value` e `onValueChange`. Se as opções não couberem na tela, prefira `Select`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import { RadioGroup, RadioGroupItem } from "@portais-orion/ui/radio-group";
```

O import por subpath traz só `radio-group`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.
