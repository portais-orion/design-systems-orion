---
title: RadioGroup
description: "Escolha de exatamente uma opção entre poucas, todas visíveis ao mesmo tempo."
---

Controle com `value` e `onValueChange`. Se as opções não couberem na tela, prefira `Select`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/radio-group" story="Default" />

## API Reference

`RadioGroup` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
