---

Componha com `TabsList`, `TabsTrigger` e `TabsContent`; a variante escolhida em `TabsList` é herdada pelos gatilhos.

Disponível em `@design-systems-orion/ui`, na categoria **Navegação**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@design-systems-orion/ui/tabs";
```

O import por subpath traz só `tabs`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

### TabsList

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"line" \| "default"` | `default` |

### TabsTrigger

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"line" \| "default"` | `default` |

Além destas, `Tabs` aceita as props do elemento/primitivo que envolve.
