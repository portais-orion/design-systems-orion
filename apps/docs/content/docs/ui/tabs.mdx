---
title: Tabs
description: "Alterna entre painéis de conteúdo no mesmo contexto, sem navegar."
---

Componha com `TabsList`, `TabsTrigger` e `TabsContent`; a variante escolhida em `TabsList` é herdada pelos gatilhos.

Disponível em `@portais-orion/ui`, na categoria **Navegação**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

### TabsList

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"line" \| "default"` | `default` |

### TabsTrigger

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"line" \| "default"` | `default` |

Além destas, `Tabs` aceita as props do elemento/primitivo que envolve.
