# Button

Um componente da biblioteca `@portais-orion/ui` agrupado em **Layout**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

<Preview>

  </div>
</Preview>

```tsx
import { Button } from "@portais-orion/ui";

export default function Example() {
  return (
    <Button {/* props */} />
  )
}
```
