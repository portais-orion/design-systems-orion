Para navegar até outra página, passe `render` com um link — assim o elemento continua sendo um `<a>` para o leitor de tela e o teclado. Ícones passados como filhos são dimensionados automaticamente.

Disponível em `@portais-orion/ui`, na categoria **Ações**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/button" story="Default" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `"link" \| "default" \| "outline" \| "secondary" \| "ghost" \| "destructive"` | `default` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `default` |

Além destas, `Button` aceita as props do elemento/primitivo que envolve.
