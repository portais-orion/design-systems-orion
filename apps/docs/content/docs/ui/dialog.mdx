Controla apenas o estado de abertura: o conteúdo visível vem de `DialogContent`. Para confirmar uma ação destrutiva use `AlertDialog`, que impede o fechamento acidental.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @portais-orion/ui
```

## Import

```tsx
import {
	Dialog,
	DialogPortal,
	DialogOverlay,
	DialogClose,
	DialogTrigger,
	DialogContent,
	DialogHeader,
	DialogFooter,
	DialogTitle,
	DialogDescription,
} from "@portais-orion/ui/dialog";
```

O import por subpath traz só `dialog`. Importar de `@portais-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

`Dialog` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
