---
title: AlertDialog
description: "Modal que exige uma decisão antes de prosseguir, para ações destrutivas ou irreversíveis."
---

Diferente do `Dialog`, não fecha ao clicar fora nem no Esc: a saída é sempre por `AlertDialogAction` ou `AlertDialogCancel`.

Disponível em `@design-systems-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import {
	AlertDialog,
	AlertDialogPortal,
	AlertDialogOverlay,
	AlertDialogTrigger,
	AlertDialogContent,
	AlertDialogHeader,
	AlertDialogFooter,
	AlertDialogTitle,
	AlertDialogDescription,
	AlertDialogAction,
	AlertDialogCancel,
} from "@design-systems-orion/ui/alert-dialog";
```

O import por subpath traz só `alert-dialog`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

`AlertDialog` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
