---
title: AlertDialog
description: "Modal que exige uma decisão antes de prosseguir, para ações destrutivas ou irreversíveis."
---

Diferente do `Dialog`, não fecha ao clicar fora nem no Esc: a saída é sempre por `AlertDialogAction` ou `AlertDialogCancel`.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/alert-dialog" story="Confirmacao" />

## API Reference

`AlertDialog` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
