---
title: Skeleton
description: "Marcador pulsante que ocupa o espaço do conteúdo enquanto ele carrega."
---

Não tem tamanho próprio: defina altura e largura via `className` para espelhar o conteúdo real e evitar deslocamento de layout na troca.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

`Skeleton` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
