`type="single"` (padrão) mantém apenas uma seção aberta; `type="multiple"` permite várias. Componha com `AccordionItem`, `AccordionTrigger` e `AccordionContent`.

Disponível em `@design-systems-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import {
	Accordion,
	AccordionItem,
	AccordionTrigger,
	AccordionContent,
} from "@design-systems-orion/ui/accordion";
```

O import por subpath traz só `accordion`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `type` | `"multiple" \| "single"` | `single` | `single` mantém uma seção aberta por vez; `multiple` permite várias. |
| `className` | `string` | — | — |

Além destas, `Accordion` aceita as props do elemento/primitivo que envolve.
