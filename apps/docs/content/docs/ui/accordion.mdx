description: "Lista de seções expansíveis."

`type="single"` (padrão) mantém apenas uma seção aberta; `type="multiple"` permite várias. Componha com `AccordionItem`, `AccordionTrigger` e `AccordionContent`.

Disponível em `@portais-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `type` | `"multiple" \| "single"` | `single` | `single` mantém uma seção aberta por vez; `multiple` permite várias. |
| `className` | `string` | — | — |

Além destas, `Accordion` aceita as props do elemento/primitivo que envolve.
