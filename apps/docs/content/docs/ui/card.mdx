Componha com `CardHeader`, `CardContent` e `CardFooter`; o padding é responsabilidade dessas partes, não da raiz.

Disponível em `@design-systems-orion/ui`, na categoria **Exibição de dados**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import {
	Card,
	CardHeader,
	CardFooter,
	CardTitle,
	CardDescription,
	CardContent,
} from "@design-systems-orion/ui/card";
```

O import por subpath traz só `card`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

para a lista completa.
