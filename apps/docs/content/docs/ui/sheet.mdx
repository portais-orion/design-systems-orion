---

O lado é escolhido em `SheetContent` pela prop `side`.

Disponível em `@design-systems-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import {
	Sheet,
	SheetPortal,
	SheetOverlay,
	SheetTrigger,
	SheetClose,
	SheetContent,
	SheetHeader,
	SheetFooter,
	SheetTitle,
	SheetDescription,
} from "@design-systems-orion/ui/sheet";
```

O import por subpath traz só `sheet`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `right` |

Além destas, `Sheet` aceita as props do elemento/primitivo que envolve.
