---
title: Sheet
description: "Painel que desliza a partir de uma borda da tela, para conteúdo auxiliar sem trocar de página — filtros, detalhes ou navegação em telas estreitas."
---

O lado é escolhido em `SheetContent` pela prop `side`.

Disponível em `@portais-orion/ui`, na categoria **Feedback**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/sheet" story="Right" />

## API Reference

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `right` |

Além destas, `Sheet` aceita as props do elemento/primitivo que envolve.
