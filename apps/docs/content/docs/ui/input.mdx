Aceita qualquer `type` de `<input>`; associe um `Label` via `id`/`htmlFor` e use `FormField` (blocks) quando precisar de rótulo, ajuda e mensagem de erro juntos.

Disponível em `@design-systems-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Input } from "@design-systems-orion/ui/input";
```

O import por subpath traz só `input`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

`Input` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
