---
title: Switch
description: "Alterna uma opção que vale imediatamente, sem confirmação."
---

Quando a mudança só se aplica após salvar o formulário, prefira `Checkbox`.

Disponível em `@design-systems-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# Primitives e blocks são packages separados: instale só o que for usar.
pnpm add @design-systems-orion/ui
```

## Import

```tsx
import { Switch } from "@design-systems-orion/ui/switch";
```

O import por subpath traz só `switch`. Importar de `@design-systems-orion/ui` também
funciona e dá no mesmo bundle — os packages são `sideEffects: false`.

## API Reference

de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
