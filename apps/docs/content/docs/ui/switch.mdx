---
title: Switch
description: "Alterna uma opção que vale imediatamente, sem confirmação."
---

Quando a mudança só se aplica após salvar o formulário, prefira `Checkbox`.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<ComponentPreview name="ui/switch" story="Default" />

## API Reference

`Switch` não declara props próprias: repassa as props do primitivo
de Base UI que envolve, mais `className`. Consulte a [documentação do Base UI](https://base-ui.com/react/overview/quick-start)
para a lista completa.
