# Switch

Um componente da biblioteca `@portais-orion/ui` agrupado em **Forms**.

## Instalação

```bash
# Como nosso ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## Uso

<Preview>
  <div className="text-muted-foreground text-sm">

  </div>

```tsx
import { Switch } from "@portais-orion/ui";

export default function Example() {
  return (
    <Switch {/* props */} />
  )
}
```

## Exemplos

### Checked
```tsx
<Switch {...{ defaultChecked: true }} />
```

### Disabled
```tsx
<Switch {...{ disabled: true }} />
```

### DisabledChecked
```tsx
<Switch {...{ disabled: true, defaultChecked: true }} />
```
