---
title: MultiSelect
description: "Seleção de várias opções com busca, exibindo as escolhas como chips removíveis."
---

Acima de `maxDisplay` chips, o excedente vira um contador "+N". `options` aceita itens planos ou agrupados.

Disponível em `@portais-orion/ui`, na categoria **Formulários**.

## Instalação

```bash
# O ecossistema é um monorepo e importamos o package completo:
pnpm add @portais-orion/ui
```

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `value`\* | `string[]` | — | — |
| `onValueChange`\* | `(value: string[]) => void` | — | — |
| `options`\* | `AdvancedOptions` | — | — |
| `placeholder` | `string` | `Selecione...` | — |
| `searchPlaceholder` | `string` | — | Mantido por compatibilidade de API: no padrão Base UI o próprio campo é a busca. |
| `emptyMessage` | `string` | `Nenhuma opção encontrada` | — |
| `disabled` | `boolean` | `false` | — |
| `clearable` | `boolean` | `false` | — |
| `maxDisplay` | `number` | `3` | Chips visíveis antes do indicador +N. |
| `className` | `string` | — | — |
| `contentClassName` | `string` | — | — |
| `id` | `string` | — | — |
| `aria-label` | `string` | — | — |

\* Prop obrigatória.

Além destas, `MultiSelect` aceita as props do elemento/primitivo que envolve.
