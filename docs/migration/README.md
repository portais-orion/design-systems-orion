# Migração dos portais

Espaço reservado para planos executáveis de migração por portal (uma pasta por portal quando a fase iniciar).

Ordem oficial: ver `docs/architecture/migration-strategy.md`.
Contexto por portal para agentes: `ai/context/05-migration-supertrans.md` e `ai/context/06-migration-aurora.md`.

Nada nesta pasta autoriza alterar os repositórios dos portais — a migração acontece nos repos deles, em sprints próprias.
